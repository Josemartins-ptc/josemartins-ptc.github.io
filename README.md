# noshio

Source of https://josemartins-ptc.github.io/ — small developer tools for working with AI coding agents.

- `/` — home and product list
- `/ariadne/` — Ariadne, a complexity guard for Claude Code ([plugin](https://github.com/Josemartins-ptc/ariadne-plugin))

Plain HTML, CSS and JavaScript; no build step. Preview locally with `python3 -m http.server 8000`.
A new product is a new folder plus a card on the home page.
