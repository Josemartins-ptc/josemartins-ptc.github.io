Ariadne

The thread out of tangled code.

Ariadne scores every function Claude writes or changes. When one is too complex, too long or too deeply nested, Claude is told exactly why and refactors it before the turn can end. Then your lint and tests run.

Why

Agents write code fast. Nobody checks it as fast.

A function grows one reasonable change at a time, until nobody wants to touch it. Reviews catch it late, when the agent that wrote it has long lost the context. Ariadne catches it during the turn.

1 edit

How long a too-complex function goes unnoticed: Ariadne checks right after every edit, while Claude still has the context.

5

Scores per function: cyclomatic, cognitive, length, parameters and nesting. One rule set, the same in every language.

100%

Deterministic. No model judges your code: the same file gives the same scores on every machine, byte for byte.

What it measures

Five scores, one limit each

A function fails when any score is above its limit; equal passes. The defaults below can be changed per project, language or folder.

Cyclomatic

How many paths run through the function.

limit 10 · Go 15

Cognitive

How hard it is to read. Nested code costs more.

limit 15

Length

How many lines the function has.

limit 80 · .tsx/.jsx 120

Parameters

How many parameters it takes.

limit 7

Nesting

How deep its ifs, loops and switches go.

limit 4

How it works

A gate inside Claude's own loop

01 · edit

After every edit

Ariadne scores the functions Claude just changed. Over a limit? Claude hears which one and why, right away.

02 · refactor

Claude simplifies

Guard clauses, early returns, named helpers. The limits are your rules: Claude is told so, and Ariadne blocks its edits to the settings file.

03 · stop

Before the turn ends

Every changed function is checked again, then your lint and tests run. Something still red? Claude keeps working, up to 5 rounds by default.

04 · done

One status line

Ariadne ✓ lint passed · 3 functions within limits · tests passed

Install

Two commands. No Rust, no build.

Ready-built for macOS and Linux, on Apple silicon, ARM and Intel.

1 · Add Ariadne to Claude Code

claude plugin marketplace add Josemartins-ptc/ariadne-plugin
claude plugin install ariadne@ariadne-plugins

Already in a session? Run /reload-plugins. No SSH key for GitHub? Use https://github.com/Josemartins-ptc/ariadne-plugin.git as the address.

2 · Set up a project

/ariadne:init
  1. Pick the languages the project uses.
  2. Take the defaults, or set your own limits and commands.
  3. Check the file it writes, .ariadne.toml, and commit it.

Then ask for a change. Every turn ends with an Ariadne status line.
