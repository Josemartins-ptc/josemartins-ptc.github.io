How noshio builds

Three rules for every tool

01

Deterministic

The same input gives the same answer, every time and on every machine. No model in the loop, no surprises.

02

Inside the loop

Feedback reaches the agent while it is still working, so it fixes the problem itself.

03

Nothing to babysit

One install, sensible defaults, plain text settings. No accounts, no servers, no tracking.
